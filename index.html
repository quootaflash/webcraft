FAQ

Pertanyaan Umum

Berapa lama proses pengerjaannya?

Untuk paket Basic, proses memakan waktu 3-4 hari kerja setelah data lengkap kami terima. Untuk paket Professional dan Executive, kami menargetkan penyelesaian dalam 2-3 hari kerja.

Apakah data saya aman?

Sangat aman. Kami menjaga kerahasiaan data klien dengan ketat. Data Anda hanya digunakan untuk keperluan penulisan dokumen dan akan dihapus dari server kami setelah 30 hari.

Bagaimana sistem revisinya?

Kami menyediakan revisi untuk memastikan dokumen sudah sesuai dengan ekspektasi Anda. Revisi mencakup perbaikan tata bahasa, struktur, atau gaya penulisan, namun tidak menambah pengalaman kerja baru.

Apa bedanya CV ATS dengan CV biasa?

CV ATS dirancang dengan format dan kata kunci tertentu agar bisa dibaca oleh software rekruter perusahaan besar. CV biasa seringkali gagal melewati sistem ini meskipun kualifikasi Anda bagus.
